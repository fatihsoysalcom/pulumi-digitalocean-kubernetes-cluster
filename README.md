# Pulumi DigitalOcean Kubernetes Cluster

This example demonstrates how to provision a DigitalOcean Kubernetes (DOKS) cluster using Pulumi with Python. It defines the cluster's region, Kubernetes version, and a default node pool configuration.

## Language

`python`

## How to Run

1. Install Pulumi: https://www.pulumi.com/docs/get-started/install/
2. Set your DigitalOcean token: pulumi config set digitalocean:token YOUR_DIGITALOCEAN_TOKEN
3. Run: pulumi up
